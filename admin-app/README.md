# Film Sospeso 관리 웹앱 설치 가이드

문의함 · 고객사/담당자 · 프로젝트 · 일정(구글 캘린더) · 입금 · 대시보드를 한 화면에서 관리합니다.
데이터는 전부 기존 **'Film Sospeso 홈페이지' 시트**에 그대로 저장됩니다.

```
홈페이지 문의 폼 ──(공개)──▶ 문의 폼 스크립트 (apps-script/)  ──▶  '문의' 탭 + 알림 메일
                                                                     ▲
팀원 ──(구글 로그인 + 허용 목록)──▶ 관리 웹앱 (admin-app/) ─────────┘  + 구글 캘린더
```

두 스크립트는 **반드시 별도 프로젝트**로 둡니다. 공개 주소(문의 폼)로는 시트에 한 줄 쓰는 것 외에 아무것도 할 수 없게 하기 위해서입니다.

## 1. 프로젝트 만들기
1. https://script.google.com → **새 프로젝트** → 이름: `Film Sospeso 관리`
2. `Code.gs` 내용을 이 폴더의 `Code.gs` 로 교체
3. 왼쪽 **+ → HTML** → 이름 `Index` → `Index.html` 내용 붙여넣기
4. ⚙ **프로젝트 설정** → "편집기에서 appsscript.json 매니페스트 파일 표시" 체크 → `appsscript.json` 교체

## 2. 스크립트 속성 (설정값)
⚙ 프로젝트 설정 → 맨 아래 **스크립트 속성 추가**

| 속성 | 값 |
|---|---|
| `SPREADSHEET_ID` | 시트 주소 `docs.google.com/spreadsheets/d/`**여기**`/edit` |
| `ALLOWED_EMAILS` | `filmsospeso@gmail.com, 팀원1@gmail.com, 팀원2@gmail.com` |
| `CALENDAR_ID` | (선택) 팀 공용 캘린더 ID — 아래 4번 참고 |

## 3. 팀원에게 시트 공유
시트 → **공유** → 팀원 이메일을 **편집자**로 추가.
(관리 웹앱은 "접속한 사람의 권한"으로 동작하므로, 시트 공유가 실제 출입증입니다. 일반 액세스는 **제한됨** 유지)

## 4. 팀 공용 캘린더 (권장)
1. 구글 캘린더 → 다른 캘린더 **+** → **새 캘린더 만들기** → `Film Sospeso 일정`
2. 그 캘린더 설정 → **특정 사용자와 공유** → 팀원을 "일정 변경 가능" 권한으로 추가
3. 같은 화면 아래 **캘린더 ID** 를 복사해 `CALENDAR_ID` 에 입력

## 5. 배포
**배포 → 새 배포 → 유형: 웹 앱**
- 다음 사용자 인증 정보로 실행: **웹 앱에 액세스하는 사용자**
- 액세스 권한: **Google 계정이 있는 모든 사용자**
  (허용 목록 + 시트 공유 둘 다 통과해야 들어올 수 있습니다)

발급된 `/exec` 주소를 팀원에게 공유하고 북마크하세요.
처음 접속 시 "Google에서 확인하지 않은 앱" 경고가 뜨는데, 직접 만든 앱이라 정상입니다 → **고급 → 이동**.

## 6. 시트 구조 맞추기
- 탭 이름이 다르면 `Code.gs` 맨 위 `TABS` 만 고치면 됩니다.
- 화면은 각 탭의 **1행 머리글**을 읽어 자동으로 만들어지고, **2행에 걸린 드롭다운**이 선택 상자가 됩니다.
- 대시보드·고객 등록·캘린더가 쓰는 열은 `FIELDS` 의 이름 후보로 찾습니다(예: 입금액/금액).
- `할일 및 미팅` 탭에는 캘린더 연결용 `캘린더ID` 열이 처음 일정 등록 때 맨 끝에 자동 추가됩니다.

## 안전장치 요약
- 모든 서버 함수가 로그인 계정 + 허용 목록을 확인 (기본값: 아무도 허용 안 함)
- 문의 내용은 화면에 텍스트로만 표시 → 문의에 스크립트를 넣어도 실행되지 않음
- 시트에 쓸 때 `=`, `+`, `-`, `@` 로 시작하는 값은 수식으로 실행되지 않게 처리
- 두 사람이 같은 행을 동시에 고치면 나중 사람에게 "새로고침" 안내 (덮어쓰기 방지)
- 바뀐 칸만 저장 → 시트의 수식·체크박스·서식 보존. 행 삭제 기능은 일부러 넣지 않음(시트에서 직접)
