# Film Sospeso Website
This is a simple static website for the video production company **Film Sospeso**.

## Features
- About section with company history (details in the attached *Out of Frame* PDF).
- Equipment list.
- Contact information.
- Hosted via GitHub Pages for quick online preview.

## Local Development
Run a simple static server:
```bash
python -m http.server 8000
```
Then open <http://localhost:8000>.

## Deployment
Push to GitHub and enable GitHub Pages on the `main` branch.
